\# Lab6\_Git - Storage Estimator



\## Purpose

A Python program to estimate total storage and convert between GB and MB for Lab 6 Git practice.



\## How to Run

python storage\_estimator.py



\## Example Input/Output

Enter storage in GB: 2

2 GB is equal to 2048 MB - Improved Output



Enter number of files: 5

Enter avg size in MB: 100

Estimated total: 500 MB
